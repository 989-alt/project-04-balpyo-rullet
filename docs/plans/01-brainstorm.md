# Brainstorm — 발표 차례 룰렛

> AI 자체 판단 (무인 세션). YAGNI 적용. TV 시연 + 1초 안에 결과.

## 꼭 필요한 기능 (MUST) — 5개

1. **명단 빠른 입력**
   - 좌측 사이드 패널에 한 줄 textarea(번호. 이름 또는 이름만 한 줄씩) → "적용" 버튼.
   - 번호가 없으면 자동 1부터 부여. 빈 줄·중복 무시.
   - localStorage 자동 저장.

2. **3가지 추첨 모드**
   - **무작위**: 매번 전체에서 균등 무작위.
   - **방금 뽑힌 사람 제외**: 최근 1명 제외(연속 호명 방지).
   - **오늘 안 한 사람만**: "오늘" 카운트 0인 학생만 후보. 모두 1회 이상이면 자동 초기화 후 다시 시작(메시지).
   - 라디오 버튼 한 줄로 즉시 전환.

3. **스핀 애니메이션 + 결과 강조**
   - 중앙 거대 카드 안에서 이름들이 0.8~1.2초 동안 빠르게 교체(60fps requestAnimationFrame, 가속 후 감속).
   - 멈춘 학생 이름은 화면 절반 크기(>=120px) + 색 강조(Raycast accent yellow).
   - prefers-reduced-motion 사용자에겐 100ms 즉시 표시.
   - 키보드: Space/Enter 한 번이면 스핀.

4. **공정성 카운트 시각화**
   - 우측 패널: 학생별 "오늘" / "전체" 누적 호명 횟수 + 미니 가로 바.
   - 정렬: 호명 적은 순(공정성에 도움). 0회는 노란 점 표시.
   - "오늘 초기화" / "전체 초기화" 두 버튼.

5. **JSON 백업·복원 + 명단 초기화**
   - "JSON 내보내기": 명단·카운트 모두 다운로드(파일명에 날짜).
   - "JSON 가져오기": 파일 선택 → 검증 후 덮어쓰기(확인 다이얼로그).
   - "전체 초기화": 명단·카운트 전부 제거(확인 다이얼로그).

## 있으면 좋은 기능 (SHOULD) — 3개

1. **짧은 효과음 (선택)**
   - 스핀 시 tick-tick(WebAudio API로 직접 합성, 외부 파일 없이). 기본 OFF, 사용자 ON 토글. localStorage 저장.

2. **방금 뽑힌 사람 임시 표시 큐**
   - 화면 하단 작은 칩 행으로 최근 5명 호명 순서 표시(가장 최근이 좌측). 한눈에 흐름 파악.

3. **인쇄용 명단 보기 단축키**
   - Ctrl/Cmd+P 시 카운트 표가 깔끔히 인쇄되도록 print CSS 1조각 추가. (선생님이 학기말 회고용)

## 절대 금지 기능 (MUST NOT) — 4개

1. **사진 업로드 / 학생 얼굴 표시** — 정책 위반. 이름·번호만.
2. **서버 전송 / 외부 공유 / 분석 추적** — 어떤 fetch도 외부로 가지 않음. CDN 의존 0.
3. **모둠 자동 편성 · 성적 입력 · 평어 생성** — Scope creep. 이 앱은 "한 명 뽑기" 한 가지에 집중.
4. **로그인 / 클래스 동기화 / 다중 학급 관리** — 한 학급(현재 명단) 한 화면.  
   다른 학급은 JSON 내보낸 후 새 JSON 가져오기로 전환.

## 핵심 사용자 시나리오 (P0)

1. 처음 화면 → 좌측 textarea에 25명 이름 붙여넣기 → "적용".
2. 우측에 25명 카운트 표 0/0으로 자동 생성.
3. 가운데 "스핀" 버튼 클릭 → 1초 후 한 학생 이름이 큰 글씨로 강조 → "오늘" 카운트 +1.
4. "오늘 안 한 사람만" 모드로 전환 → 다시 스핀 25번 → 26번째 시도 시 안내 메시지 + 자동 초기화.
5. "JSON 내보내기" → 파일 다운로드 후 "JSON 가져오기"로 복원해도 동일 상태.

## 비기능 요구사항

- TV 1080p 거리에서 읽혀야 함: 본문 >= 24px, 핵심 이름 >= 96px.
- 색 대비 4.5:1 이상 (Raycast `body #cdcdcd` on `#07080a` 만족).
- 키보드만으로 명단 입력→모드 변경→스핀→내보내기 가능.
- prefers-reduced-motion 존중.
- 1MB 미만 단일 HTML(자기완비).
