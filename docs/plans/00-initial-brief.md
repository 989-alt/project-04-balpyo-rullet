# Day 04 — 발표 차례 룰렛 (Name Picker Roulette)

## 토픽 ID & 제목
- 번호: #004
- 제목: 발표 차례 룰렛 — 이름 뽑기 (국어/학급 공통)

## 콘텐츠 주제·목표
학급 명단을 한 번만 등록해 두고, 발표·질문할 학생을 무작위/가중치로 추첨. "오늘 누가 발표?"의 부담을 0초로 줄인다.

## 포함 기능 (원본)
- 명단 입력 / JSON 가져오기·내보내기
- 단순 무작위 · "방금 뽑힌 사람 제외" · "오늘 안 한 사람만" 모드
- 학생별 누적 카운트(공정성 시각화)
- 스핀 애니메이션 + 사운드(짧고 거슬리지 않게)
- 명단 초기화 / 백업

## 배제 기능 (원본)
- 사진 업로드
- 학생 데이터 서버 전송 / 외부 공유
- 학생 개인 통계의 외부 발행

## 환경
- 대상: 초3~6학년
- 사용 환경: 교실 TV(전체 시연) — 큰 글씨, 강한 대비, 한눈에 보이는 결과
- 단일 HTML 파일 + vanilla JS/CSS. CDN 의존 0 (헤드리스 환경 안정성)

## 데이터
- localStorage 전용 (학생 이름·번호·카운트). 서버 X.
- JSON export/import 로 백업·이관

## AI
- Gemini 사용 ✕

## 디자인
- 메인 브랜드: **Raycast** (다크 캔버스, 작은 hairline 카드, Inter)
- 보조: **Playstation** (스핀 룰렛 즐거움 — 강조 색 일부 차용)

## 제약 (이 토픽 한정)
- 사진·이름 외 어떤 개인정보도 다루지 않음.
- TV 시연용이므로 큰 폰트(>= 24px 본문) + 4.5:1 이상 대비.
- 룰렛 애니메이션은 prefers-reduced-motion 존중.
- 키보드만으로 모든 동작 가능(focus-visible).
